# Seasaide.Cyou
> Seaside.cyou is a personal site for the Sai persona and is a unified archive for holding all media in relation.


## Features
- Interactive Sakura background effect.
- Integrated live & recent Spotify status displayed.
- Data is managed & stored on Sanity.io backend meaning edits on site requires no coding.
- Footer has up to 15+ quotes shuffling with wise words to live by.
- Updated blogs post synced with calendar including pinned posts.
- Podium of favorite songs and curated playlists of best hits.
- Functionality for Tetris app hidden in the library section (easter egg), integrated with seasonal leaderboards and online play.
- Updated with projects in progress and/or completed.
- Dynamic gallery slides with 3D carousel layout with surprises hidden in some photos.
